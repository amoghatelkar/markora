First launch (no Terminal required)

Markora is not yet distributed with paid Apple/Microsoft signatures, so each OS shows a one-time security step. Use the steps below — all menus and dialogs.

macOS

  1. Download the .dmg above (~100 MB). A tiny file means a failed download — try GitHub Releases.
  2. Open the .dmg and drag Markora into Applications.
  3. Right-click Markora → Open → Open (not double-click the first time).

Blocked already? System Settings → Privacy & Security → Open Anyway.

Windows

  1. Run Markora-Setup-*.exe.
  2. SmartScreen: More info → Run anyway.

Linux

  1. In a terminal: chmod +x Markora-*.AppImage
  2. Run: ./Markora-*.AppImage (or enable “Allow executing” in file properties).

Older builds only: if you see a chrome-sandbox error, run ./Markora-*.AppImage --no-sandbox or download the latest release.
